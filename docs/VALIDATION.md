## Numerical checks

**Equilibrium moments:** the nine equilibrium populations reproduce prescribed density and momentum to a 1e-14 tolerance when evaluated in the test's Float64 arithmetic. This does not imply Float64 storage in the solver.

**Uniform periodic flow:** TRT and BGK preserve equilibrium on a 32×32 lattice through 300 steps, within the Float32 test tolerances.

**Shear-wave decay:** fully periodic 48×48 lattice, initial ux = 0.016 sin(2πy/48), uy=0, rho=1, lattice kinematic viscosity 0.1, 600 steps. The measured velocity is projected onto the same sine mode. Analytical amplitude is A(t)=A(0) exp(-nu k² t).

| Collision | Measured amplitude | Analytical amplitude | Relative amplitude error |
|---|---:|---:|---:|
| TRT | 0.00571902578 | 0.00572306746 | 0.0706% |
| BGK | 0.00571246015 | 0.00572306746 | 0.1853% |

This is verification of viscous decay in one smooth periodic setting. It is not an overall CFD error bound or a body-flow accuracy claim. The executable test allows up to 1.5% relative error to distinguish significant regressions from benign platform rounding; the values above are the observed run.

**Closed cavity:** 48×48 preset lattice after 1200 steps; mean fluid lattice density was 1.000126652, approximately 0.0126652% above the initialized reference density. Positive and negative interior X velocity verify that recirculation develops; no-slip solid-node field values remain zero. The permitted mean-density deviation in the test is 0.02%. This is a sanity / drift check, not a quantitative comparison to a published cavity centerline benchmark.

**Open channel:** after 1000 steps on a 96-column lattice, interior inlet nodes recover prescribed horizontal velocity and outlet nodes recover density 1 to within 2e-6 in lattice units. Developed Poiseuille-profile error and pressure-gradient convergence were not established by this test.

**Worker protocol:** the actual `src/worker.js` is hosted by a small Node `worker_threads` adapter. Its transferable Float32 snapshots agree exactly with the direct CPU solver after 120 and 121 steps. This verifies the worker message logic in Node; it is not a claim that browser Worker execution was available in this environment.

Other tests exercise all six preset definitions, rasterized solid membership, malformed / nonphysical / oversized input rejection, independent undo/redo snapshots, and CSV/VTK physical-field serialization.

## Browser checks

The full standalone application was loaded into an allowed in-memory Chromium document using Playwright. The browser's navigation policy and absence of WebGPU/worker availability were respected. No security policy was disabled, no mocked velocity field was injected, and the application's real cooperative fallback advanced the numerical solver.

The suite checks initialization, finite flow advancement, mesh overlay, field selector and legend, body-property transactions, undo/redo, create/select/delete, pointer-drawn circles, measured probes, reinitialization with the probe table open, seven export generators, case-file round trip, sanitized SVG import, all seven workflow ribbons, all six examples, example gallery, keyboard run/pause, light/dark responsive layouts, and absence of uncaught JavaScript errors.

Exports were verified by examining the actual Blob data generated by the application. The test intercepts the final download-anchor activation to avoid prohibited browser navigation. Consequently it verifies file generation, not the operating system's native download UI.

All six examples were advanced 80 steps on reduced 96-column grids for UI smoke testing. This is not a long-time stability claim. The final screenshots show the actual airfoil result after 640 steps on a 384×173 lattice; they are not a converged solution or performance benchmark.

## Reproduce

```sh
npm test
python3 -m pip install playwright
python3 -m playwright install chromium
npm run test:browser
```

Default browser testing serves the actual modular app at localhost:4173. The suite requests WebGPU availability; when an adapter is obtained it attempts a 128-step cylinder GPU/CPU comparison, requiring maximum absolute difference below 1e-4 across the stored macroscopic field. Passing that check would be useful initial parity verification, not comprehensive GPU validation.

Use `CHROMIUM_PATH=/path/to/chromium` to choose a browser. Use `python3 tests/browser.py --memory` only for the in-memory standalone path. The recorded `not-executed` result must not be silently converted to a pass when distributing or quoting this report.
